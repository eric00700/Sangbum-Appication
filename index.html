이 기계의 설정 기록

저장한 설정은 기계 탭의 해당 기계 카드에 표시됩니다.

데이터 카운터 화면 해설

기계 위쪽 데이터 카운터(사이드 디스플레이)의 항목입니다. 사진 속 기계(엑스 에반게리온 계열 CR기, 기계 번호 310)를 기준으로 읽었습니다.

촬영 탭 입력칸이 채워집니다. 확인 후 저장하면 기계·순위 탭이 어떻게 보이는지 바로 테스트할 수 있습니다.

일별 그래프 화면 (日別グラフ)

왼쪽 종합 데이터와 오른쪽 일별 그래프가 한 화면에 나오는 형식입니다.

계산: 대당 ÷ 초당 = 1일 전 19÷13 ≈ 1.46, 2일 전 7÷5 = 1.4 (초당 1회당 평균 대당 수. 연속이 길수록 커집니다)

큰 빨간 7세그먼트 숫자(오늘 대당 횟수, 스타트)는 OCR이 가장 많이 틀리는 부분입니다. 숫자는 저장 전에 화면과 꼭 대조하세요. 카운터 전체가 프레임에 꽉 차도록, 빛 반사가 없는 각도로 찍으면 인식률이 올라갑니다.

연속 그래프 분석 (連続グラフ)

선 색으로 구분합니다. 빨강 = 오늘(本日), 노랑 = 1일 전, 초록 = 2일 전, 보라 = 연속 당첨으로 크게 오른 구간(ラッキートリガー). 세로축은 출옥(획득 구슬) 누적입니다.

영역·눈금 보정 (결과가 이상할 때)

값은 사진 크기에 대한 %입니다. 미리보기의 흰 점선 상자가 그래프 안쪽을 덮고, 수평선 두 개가 0선과 최상단 눈금선에 맞아야 합니다.
