# Sangbum App

일본어·영어·중국어 실시간 통역, 일본·태국·중국 음식 메뉴판 번역, 파칭코 데이터 분석을 한 곳에 모은 모바일 웹앱입니다.
GitHub Pages에 올리면 폰에서 주소만 열어 바로 쓰고, 홈 화면에 앱처럼 설치할 수 있습니다.

## 1. GitHub에 올리기 (컴퓨터에서, 약 5분)

1. https://github.com 에 로그인합니다. 계정이 없으면 먼저 가입합니다.
2. 오른쪽 위 **+ → New repository** 를 누릅니다.
3. Repository name에 `sangbum-app` 을 입력하고 **Public** 을 선택한 뒤 **Create repository** 를 누릅니다.
4. 새 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
5. 받은 `sangbum-app.zip` 의 압축을 풀고, **안에 있는 파일 전부**(`index.html`, `sw.js`, `manifest.webmanifest`, 아이콘 3개, `.nojekyll`, `README.md`)를 업로드 화면에 끌어다 놓습니다.
   - 폴더째가 아니라 파일들이 저장소 맨 위(루트)에 있어야 합니다.
   - `.nojekyll` 은 점으로 시작해서 탐색기에 안 보일 수 있습니다. 없어도 동작은 합니다.
6. 아래쪽 **Commit changes** 를 누릅니다.

## 2. 인터넷에 공개하기 (GitHub Pages 켜기)

1. 저장소 위쪽 **Settings** → 왼쪽 **Pages** 로 이동합니다.
2. **Build and deployment** 의 Source는 **Deploy from a branch** 로 둡니다.
3. Branch를 **main**, 폴더를 **/(root)** 로 고르고 **Save** 를 누릅니다.
4. 1~2분 기다린 뒤 페이지를 새로 고치면 위쪽에 주소가 나옵니다.

   `https://내아이디.github.io/sangbum-app/`

## 3. 폰에서 열고 앱으로 설치하기

**Android (Chrome)**
1. 위 주소를 Chrome으로 엽니다.
2. 메인 화면 아래의 **홈 화면에 앱 설치** 버튼을 누르거나, Chrome 메뉴(⋮) → **앱 설치** 를 누릅니다.
3. 홈 화면에 생긴 **Sangbum** 아이콘으로 실행합니다.

**iPhone (Safari)**
1. 위 주소를 **Safari** 로 엽니다. 다른 브라우저에서는 설치가 안 됩니다.
2. 아래 공유 버튼 → **홈 화면에 추가** 를 누릅니다.

## 4. 처음 사용할 때

- 카메라, 마이크 권한을 물으면 **허용** 하세요. GitHub Pages 주소는 보안 연결(https)이라 카메라와 마이크가 정상 동작합니다.
- 글자 인식(OCR)은 처음 쓰는 언어(일본어, 태국어, 중국어)의 데이터를 받느라 처음 한 번 오래 걸립니다. 인터넷 연결이 필요합니다.
- 음성 인식은 Android Chrome에서 가장 잘 됩니다. iPhone Safari는 음성 인식 지원이 제한적입니다.

## 5. 번역을 더 정확하게 (선택)

앱 안 **게임 → 번역** 탭의 「Google Cloud Translation API 키」 칸에 키를 넣으면 번역 품질이 좋아지고,
실시간 대화에서 **한국어와 상대 언어를 자동으로 구분**합니다. 이 경우 같은 키로 **Speech-to-Text API** 도 켜 두어야 합니다.

- 키는 **내 폰 브라우저에만 저장**됩니다. 코드나 GitHub에는 올라가지 않습니다.
- 저장소가 Public이므로 **키를 파일 안에 직접 적어 넣지 마세요.**
- Google Cloud 콘솔에서 키의 사용 제한을 **HTTP 리퍼러 `https://내아이디.github.io/*`** 로 걸어 두면 안전합니다.
- 사용량에 따라 요금이 발생할 수 있습니다.

## 6. 앱 수정·업데이트하기

1. GitHub 저장소에서 `index.html` 을 열고 연필 아이콘으로 수정하거나, 새 파일을 같은 이름으로 다시 업로드합니다.
2. `sw.js` 맨 위의 `sangbum-v1` 숫자를 `sangbum-v2` 처럼 올리고 저장합니다.
3. 1~2분 뒤 폰에서 앱을 완전히 닫았다가 다시 열면 새 버전이 반영됩니다.

## 7. 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| 주소를 열면 404 | Pages 설정을 저장했는지, `index.html` 이 저장소 맨 위에 있는지 확인하고 2~3분 기다리세요. |
| 설치 버튼이 안 보임 | Chrome 메뉴(⋮)에서 「홈 화면에 추가」를 쓰거나, 주소를 https로 열었는지 확인하세요. |
| 마이크·카메라가 안 켜짐 | 브라우저 주소창 왼쪽 자물쇠 → 권한에서 허용으로 바꾸세요. |
| 수정했는데 그대로 | `sw.js` 의 버전 숫자를 올렸는지 확인하고 앱을 완전히 닫았다 여세요. |
| 글자 인식이 안 됨 | 인터넷 연결을 확인하고, 밝고 정면에서 가까이 찍어 보세요. |

## 구성

| 메뉴 | 내용 |
|---|---|
| 1. 실시간 대화 | 일본어·영어·중국어 ↔ 한국어, 위아래 분리 화면, 시작 버튼 하나로 자동 통역 |
| 2. 음식점 | 일본·태국·중국 음식 메뉴판 사진 번역, 가격 원화 변환, 용어 도움말 |
| 3. 게임 | 파칭코 자동 입력, 기계·순위, 번역·사전, 설정 화면, 카운터 해설, 그래프 분석 |

번역과 인식 결과는 틀릴 수 있습니다. 금액, 알레르기, 안전, 계약처럼 중요한 내용은 반드시 확인하세요.
파칭코 분석은 지난 기록을 정리하는 참고 자료이며, 당첨 확률을 높여 주지 않습니다.
